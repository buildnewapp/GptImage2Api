# 快速开始

本指南介绍 <SiteName /> 的基础生成流程，帮助你从一个想法开始，完成第一个 AI 视频。

> 这是文档中心的首个示例页面。后续指南可以沿用相同的目录、搜索和 MDX 内容结构继续添加。

## 开始前准备

- 准备一段清晰的画面描述，包括主体、动作、环境和镜头效果。
- 如果使用图生视频模式，请准备一张主体清晰、构图稳定的参考图片。
- 登录账号，以便提交生成任务并在历史记录中查看结果。

## 生成第一个视频

1. 打开 <SiteName /> 生成器。
2. 根据素材选择文生视频或图生视频模式。
3. 选择适合的模型，并按需要设置画面比例、时长和清晰度。
4. 输入提示词；使用图生视频时，再上传参考图片。
5. 检查预计消耗后提交任务，等待生成完成。

## 提示词示例

一段有效的提示词通常包含主体、动作、场景、光线和镜头语言：

```text
一位舞者站在雨后的霓虹街道上，镜头缓慢向前推进，
衣摆随风摆动，电影感光影，细节清晰，动作自然流畅。
```

## 检查生成结果

生成完成后，重点检查主体一致性、动作连贯性、画面构图和细节稳定性。如果结果偏离预期，可以减少相互冲突的描述，并把最重要的主体和动作放在提示词前面。
